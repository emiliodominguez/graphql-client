# Project imagery

`lumenql-banner.jpg` is the README cover: 1774 × 887 pixels, with a 2:1 aspect ratio.
The optical illustration connects the name lumenql with light and clarity through amber rays,
an aperture, warm ivory paper, and ink-black editorial typography.

The root README uses an absolute raw GitHub URL so the image also resolves outside GitHub.

Generated with the built-in `image_gen` tool and exported as JPEG at quality 92 without resizing or cropping.

## Art direction

A mid-century experimental optics book cover with contemporary editorial typography.
Fine amber and burnt-orange rays pass through a dark aperture, suggesting light bringing structure
into focus. Restrained translucent ink, subtle paper texture, generous whitespace, and a limited
ivory, black, amber, and burnt-orange palette create a tactile print aesthetic.

The text reads `lumenql` and “Your data. Precisely connected.”
Avoid glossy 3D objects, chrome, neon, stock network imagery, and decorative UI elements.
